1. Install minikube
	1.1 Go to https://minikube.sigs.k8s.io/docs/start/
	1.2 In '1 Installation' menu
		1.2.1 Click latest release link on "Download and run the installer for the latest release."
		1.2.2 Open poweshell in Admin mode
		1.2.3 Run the below comand
			$oldPath = [Environment]::GetEnvironmentVariable('Path', [EnvironmentVariableTarget]::Machine)
			if ($oldPath.Split(';') -inotcontains 'C:\minikube'){
  				[Environment]::SetEnvironmentVariable('Path', $('{0};C:\minikube' -f $oldPath), [EnvironmentVariableTarget]::Machine)
			}

2. Install Docker
	2.1 Go to https://minikube.sigs.k8s.io/docs/drivers/docker/
	2.2 In standard Docker click "Install Docker 18.09 or higher (20.10 or higher is recommended)"

3. Run minikube
	3.1 Run (This will take some time)
		minikube start --driver=docker
	3.2 To make docker the default driver
		minikube config set driver docker
