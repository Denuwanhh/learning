4. Create Docker
	FROM 		- Base image
	COPY . . 	- {First dot mean} All the file that contain the docker file, except Docker file 
		          {Second dot mean} Path inside the image (root folder)
	WORKDIR		- Provide location to run all the commands (RUN, COPY)
	CMD 		- Not execute when image create, but when container start
	ENTRYPOINT 	- Not execute when image create, but when container start with some arguments
	EXPOSE 80 	- Port expose from image
